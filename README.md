# Dependable AI Initiative

*Making Open AI Technologies Safer for Organisations.*

The Dependable AI Initiative is a nonprofit, community-driven effort to help organisations **safely evaluate, adopt and operate open AI technologies** (open-weight models, agent harnesses and self-hosted AI infrastructure) through practical frameworks, independent assessments and open-source toolkits.

> **Status: early days.** We are a small founding group working in the open. This repository is our public working document: everything we are thinking, deciding and building lives here. You are welcome to read along, comment and contribute.

## How to get involved

1. **Say hello** in [Discussions → Introductions](https://github.com/Dependable-AI-Initiative/dependable-ai-initiative/discussions) and tell us what you're interested in.
2. **Share ideas or questions** in [Discussions](https://github.com/Dependable-AI-Initiative/dependable-ai-initiative/discussions).
3. **Pick up a task** labelled [`good first issue`](https://github.com/Dependable-AI-Initiative/dependable-ai-initiative/issues?q=is%3Aopen+label%3A%22good+first+issue%22) or [`help wanted`](https://github.com/Dependable-AI-Initiative/dependable-ai-initiative/issues?q=is%3Aopen+label%3A%22help+wanted%22).
4. Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.

You don't need to write code. Reviewing guidance, sharing how your organisation adopts AI, testing checklists and improving documentation all count.
