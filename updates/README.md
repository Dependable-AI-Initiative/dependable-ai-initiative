# Weekly updates

A short weekly note on what moved, what's next and where help is needed. Each update is also posted in Discussions → Announcements.

**File naming:** `YYYY-Www.md` (ISO week), e.g. `2026-W41.md`

**Format:** keep it to a few minutes' read:

```markdown
# Week NN, YYYY

## Done
## Next
## Decisions
## Help wanted
```
