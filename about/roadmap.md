# Roadmap

> **Status: indicative.** Dates are targets, not commitments. Each phase is tracked as a GitHub **milestone**; detailed work is on the project board.

## Phase 0: Foundation (Q4 2026)
*Milestone: `v0.0 – Foundation`*

- [ ] Publish vision, principles, governance and contributing guide
- [ ] Agree naming (see [decision 0001](../decisions/0001-naming.md))
- [ ] Enable GitHub Discussions, project board and labels
- [ ] Map related initiatives and our positioning

## Phase 1: Public draft (Q4 2026 – Q1 2027)
*Milestone: `v0.1 – Framework public draft`*

- [ ] Framework structure for the three areas: open-weight models, agent harnesses, AI infrastructure
- [ ] One complete worked example (e.g. evaluating an open-weight model for internal use)
- [ ] First Toolkit checklist
- [ ] Invite feedback from pilot organisations

## Phase 2: Open the doors (Q1 2027)
*Milestone: `v0.2 – Community launch`*

- [ ] 5–10 `good first issue` tasks for newcomers
- [ ] Regular open working session
- [ ] Commons evaluation template and first published evaluations
- [ ] Mapping of the Framework to existing standards

## Phase 3: v1.0 (2027)
*Milestone: `v1.0`*

- [ ] Framework v1.0 incorporating pilot feedback
- [ ] Toolkit reference tests for each Framework area
- [ ] Decide legal form, funding model and expanded governance

## How to influence the roadmap

Propose changes in [Discussions → Ideas](https://github.com/Dependable-AI-Initiative/dependable-ai-initiative/discussions). Significant changes are recorded in [`decisions/`](../decisions/).
