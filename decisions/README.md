# Decisions

A short public record of significant decisions: what we decided, why, and what we considered. This keeps our reasoning transparent and helps newcomers understand how we got here.

## Process

1. Copy [`0000-template.md`](0000-template.md) to `NNNN-short-title.md` (next number).
2. Open a pull request with status **Proposed** and announce it in Discussions.
3. Allow the comment period set out in [GOVERNANCE.md](../GOVERNANCE.md#how-decisions-are-made) (7 days for significant decisions).
4. On acceptance, change the status to **Accepted** and merge.

Decisions are never deleted. If one is replaced, mark it **Superseded by NNNN**.
