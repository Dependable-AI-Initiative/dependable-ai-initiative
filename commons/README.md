# Dependable AI Commons

*Community-maintained knowledge, evaluation results and practical implementation guidance.*

| Folder | What goes there |
|---|---|
| [`evaluations/`](evaluations/) | Published evaluation results, one file per evaluation, using the [template](evaluations/_template.md) |
| [`guides/`](guides/) | Practical implementation guidance and lessons learnt from real deployments |

## Contributing to the Commons

- Use the evaluation template so results are comparable.
- Declare any connection to the product evaluated (see the [conflict-of-interest policy](../GOVERNANCE.md#conflicts-of-interest)).
- A second contributor reviews results for reproducibility before they're merged.
- Share what didn't work as well as what did: negative results are valuable.
